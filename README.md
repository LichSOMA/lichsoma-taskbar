# LichSOMA's Taskbar

## 배포 버전·설치 안내

- **현재 버전**: 3.0.0
- **Foundry VTT**: 13 / 14 (manifest의 verified: 14)
- **최신 릴리즈**: [LichSOMA's Taskbar Releases](https://github.com/LichSOMA/lichsoma-taskbar/releases/latest)
- **설치용 manifest**: [module.json](https://github.com/LichSOMA/lichsoma-taskbar/releases/latest/download/module.json)
- **수동 설치 ZIP**: [lichsoma-taskbar.zip](https://github.com/LichSOMA/lichsoma-taskbar/releases/download/3.0.0/lichsoma-taskbar.zip)

릴리즈 첨부 파일의 `lichsoma-taskbar.zip`을 사용하세요. GitHub의 자동 생성 `Source code` 압축 파일과는 구성이 다릅니다. ZIP에는 실행 파일·자원, README와 라이선스를 포함하며, 테스트·개발용 문서와 이전 압축 파일은 포함하지 않습니다. 개발·API 문서는 GitHub 저장소에서 확인할 수 있습니다.

업데이트 전 월드를 백업하고, 교체 후 월드와 브라우저를 다시 불러오세요. 함께 사용하는 LichSOMA 모듈도 이번 릴리즈 버전으로 업데이트하는 것을 권장합니다.

## 소개

Foundry VTT용 작업표시줄 모듈입니다. Windows 스타일의 작업표시줄을 통해 열린 창을 모아 보고, 세션 중 자주 쓰는 기능에 빠르게 접근할 수 있습니다.

## 호환성·의존성

- **Foundry VTT 버전**: v13 / v14
- **언어 지원**: 한국어 / 영어
- **연동 모듈** *(선택)*: [`lichsoma-daily-calendar`](https://github.com/LichSOMA/lichsoma-daily-calendar)가 켜져 있으면 날짜·시간대 UI와 함께 쓸 수 있습니다.

## 설치

1. 모듈 폴더를 Foundry 사용자 데이터의 `Data/modules/lichsoma-taskbar`에 배치합니다.
2. 해당 폴더 바로 안에 `module.json`이 있는지 확인합니다.
3. FVTT를 시작하고 월드의 **게임 설정 → 모듈 관리**에서 **LichSOMA's Taskbar** 항목을 활성화합니다.

Manifest URL이 제공된 배포본은 모듈 설치 화면의 **Manifest URL** 입력란을 사용할 수도 있습니다.

```text
https://github.com/LichSOMA/lichsoma-taskbar/releases/latest/download/module.json
```

## 주요 기능·사용법

- **작업표시줄 커스터마이징**: 배경 **색상**과 **투명도** 조절, FPS·지연 시간 표시
- **테마**: 심플 다크(기본)·심플 라이트·터미널 그린·터미널 레드와 웹폰트 CSS를 지원합니다.
- **퀘스트 리스트**: 퀘스트·달성 목표 추가·수정, 진행/성공/실패 상태 관리
- **사용자 목록**: 접속 사용자 표시, 오프라인 표시 토글, 아바타 보기, 할당 캐릭터 시트 열기
- **호출**: 대상 사용자에게 알림·사운드 전송 (GM은 항상 가능, 플레이어는 모듈 설정에 따라 가능)
- **GM 전용(우클릭 메뉴)**: 장면으로 불러오기, 플레이어 강제 퇴장, 차단/차단 해제
- **GM/플레이어 스크린**: 다중 탭, 저널·액터 등 드래그 앤 드롭, 메모·격자·화면 크기 조절
- **시스템 메뉴**: 게임 종료·로그아웃, 새로고침, 매크로·모듈·유저 관리, 파일 탐색, 즐겨찾기
- **외부 모듈 연동 API**: 다른 모듈이 작업표시줄 버튼·활성 상태·배지를 안정적으로 등록/갱신 가능
- **기타**: 퀵슬롯 표시 토글, 바탕화면 보기(창 최소화), 태그 관리, 파일 선택 미리보기
  - 태그 관리에서는 `[태그 1][태그 A]`처럼 대괄호로 감싼 태그를 한 줄에 입력할 수 있습니다.

### 기본 사용법

#### 파일 선택창 테마

표준 파일 선택창(FilePicker)은 작업표시줄의 테마·배경색·투명도·웹폰트를 따릅니다. 셀렉터가 활성화되어 있으면 작업표시줄을 통해 테마를 상속합니다. 작업표시줄 설정창·웹폰트 편집창은 코어 UI 스타일을 유지하며, 일반 다이얼로그와 시트에는 작업표시줄 테마를 적용하지 않습니다.

#### 퀘스트 추가

1. 작업표시줄의 **퀘스트** 버튼을 클릭합니다.
2. **퀘스트 추가**로 제목과 달성 목표를 입력합니다.
3. 목표 완료 시 체크박스로 상태를 갱신합니다.

#### 스크린 활용

1. **스크린** 버튼으로 GM/플레이어 스크린을 엽니다.
2. 사이드바에서 항목을 드래그하여 스크린에 놓습니다.
3. 탭을 추가·이름·색으로 정리하고, 필요 시 우클릭으로 편집합니다.

#### 사용자 호출

1. **사용자** 버튼으로 목록을 엽니다.
2. 호출할 사용자 항목을 **우클릭**합니다.
3. **호출**을 선택하면 대상에게 알림과 사운드가 전달됩니다.

## 설정

작업표시줄의 **설정** 버튼에서 조정합니다.

1. 단독 사용 시 테마를 고르면 색상·투명도 입력란에 기본값을 채웁니다. 기본 투명도는 네 테마 모두 90%입니다.
2. 색상 선택기·색상 코드·투명도를 조정하고 **저장**하면 즉시 반영됩니다.
3. **웹폰트 CSS 편집**에서 웹폰트 CSS와 적용할 글꼴을 지정하고, 편집 창에서 별도로 저장합니다. 비우면 테마 기본 글꼴을 사용합니다.

스피커 셀렉터가 활성화되어 있으면 테마와 해당 팔레트의 배경색을 자동 적용하고 두 항목을 잠급니다. 투명도·웹폰트는 개별 값을 유지하며, 셀렉터를 비활성화하면 저장해 둔 자체 테마·색상을 다시 사용합니다.

외형 설정은 브라우저에서 월드·사용자별로 저장합니다. 다른 브라우저나 기기에는 별도로 설정해야 합니다. 스크린의 사용자 지정 탭 색상과 카드 내용은 유지합니다.
